CodeSurf — Architecture

One engine, two run modes (serverless client vs. wire front), over a versioned relay mesh. Interactive diagrams below.

The mode spectrum core concept

● serverless (default) ● wire (—connect) node

Every session runs the same engine capabilities. The only difference is where the Agent lives:

  • Mode 1 — serverless: the TUI owns its in-process Agent. Kill it and processing stops (only an externally-spawned CLI it delegated to keeps going).
  • Mode 2 — wire: codesurf --connect ws://<node> turns the TUI into a thin front. A codesurf node owns the sessions: the TUI hands off a task, streams responses live, sends follow-ups — and killing the TUI does not stop the node's turn (client-death resilience).

The relay mesh fleet scale

A logical mesh over physical spokes: every client holds one web socket to a hub; the hub registers, discovers, routes, and forwards. Thousands of clients, relays, gateways, and nodes hang off hubs while the logical topology stays any-to-any. The relay envelope is a bounded command fabric; live turn streaming rides a separate op:"session" channel on the same socket.

Control plane vs. data plane wire protocol

The relay envelope (delegate_request / delegate_reply, versioned, steward-gated, bounded) is the command plane for session/job/fleet/trace ops. Live turn content streams over the same socket as op:"session" frames — create, message, subscribe, status, destroy in, and chunk / done / created / error back. The hub ignores session frames; the node's SessionStreamServer bridges them to its session host.

— what these pieces are components

  • codesurf — the TUI + headless client (serverless by default; --connect makes it a front).
  • codesurf node — an EngineNode: hub + NodeSessionHost (sessions that outlive fronts) + job host + fleet telemetry + tracing + an auto-reaper.
  • codesurf gateway — gateway surface (OpenAI/ACP/MCP) over the same engine.
  • Reaping — session TTL/idle eviction, finished-job + trace TTL cleanup (the abandoned-session guard).
  • PTC — programmatic tool calls (CODESURF_TOOL_PRESENTATION=code|both).
