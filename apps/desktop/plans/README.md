## Findings considered and rejected

From 2026-06-12 run:

- **SEC-04 (bus subscriptionId injection)**: by-design; subscriptionIds are local to the child process; main-process compromise is not a new surface.
- **SEC-06 (webPreferences sandbox=false)**: by-design for preload scripts; `contextIsolation: true` + `nodeIntegration: false` are both confirmed enabled.
- **SEC-07 (capability enforcement gap for safe-tier)**: intentional backwards-compatibility design, documented in code.
- **SEC-08 (unbounded store writes)**: low real-world risk for local power extensions; not worth the friction.
- **ARCH-01-2026-06 (ExtensionRegistry god-object, 32 methods)**: `.plans/codesurf-hardening-decomposition.md` already covers decomposition — defer to avoid conflicts.
- **TC-03 (session archive test duplication)**: both test files run; editorial cleanup only.
- **TC-04 (characterization-only extraction tests)**: by-design for the wave-N refactor series; E2E is the safety net.
- **DX-03 (no pre-commit hooks)**: team/velocity decision; not a finding.

From 2026-07-01 run:

- **Daemon token comparison not constant-time** (`packages/codesurf-daemon/bin/codesurfd.mjs:~2822`): high-entropy UUID over loopback; timing exfiltration impractical. Optional hardening only.
- **Daemon lacks loopback-Host DNS-rebinding check**: every route is token-gated (401 without token); defense-in-depth nicety, not a finding.
- **Broker gated capabilities without executors** (`fs/shell/network/secrets/chrome/daemon` hit `default: throw` in host dispatch): inert, not exploitable; becomes relevant only when executors are added.
- **Per-token stream reducer O(n²)**: already mitigated — `useChatTileStreamBuffer.ts:24-27` batches tokens on a flush timer.
- **Tile component duplication**: not real — tiles share `TileChrome`.
- **Chat send `error` without `done` event**: renderer's error case already stops streaming UI (`useChatStreamHandler.ts:245`); the persisted-state variant IS real and is Plan 007.
- **`pets:spritesheetData` base64 sync read**: modest one-shot cost per overlay mount; acceptable for now, revisit if spritesheets grow.
- **`morphcloud`/`react-file-icon`/`web-worker` abandonment**: no release-date evidence available offline; not asserted.
