## Overview

CodeSurf is an Electron desktop app (+ web/Native targets) providing an infinite 2D canvas workspace where tiles (terminal, code editor, browser, kanban, chat) coexist. AI agents join via a local HTTP MCP 2.0 server. The renderer is a React 19 SPA; the main process owns IPC, the event bus, and MCP. File-based persistence only — no cloud sync.

## Durable Architecture Facts

### Core Layout

- `src/main/index.ts` — window management, IPC registration, app init
- `src/main/event-bus.ts` — in-process pub/sub, wildcard patterns, ring-buffer (500 events/channel), no persistence
- `src/main/mcp-server.ts` — random-port HTTP MCP 2.0 server; config written to `~/.codesurf/mcp-server.json`; 34 tools
- `src/main/ipc/` — one file per IPC feature domain
- `src/main/ipc/stream.ts` — NDJSON/SSE parser shared by all chat providers
- `src/renderer/src/App.tsx` — canvas orchestration; delegates physics composition to `hooks/useAppCanvasInteraction.ts`
- `src/renderer/src/components/` — lazy-loaded tile components (`React.lazy` + `Suspense`)
- `src/renderer/src/hooks/` — `useDetectedAgents`, `useMCPServers`
- `src/shared/types.ts` — `TileType` union and other cross-boundary types

### Canvas Engine

- Pan/zoom, drag, resize, snapping, groups, undo/redo, context menus, connection locks live in focused hooks under `hooks/useAppCanvasInteraction.ts`; App.tsx is orchestration only
- World coords = screen coords adjusted for zoom + pan offset
- Group movement recurses through nested groups
- Undo snapshots full state (max 50) — never push to undo stack in hot paths
- `useRef` heavily used to keep mutable state accessible inside event handlers without stale closures

## Chat Chip Chrome — Stable Decisions (Do Not Break)

| Component | Chrome |
|---|---|
| `ThinkingBlockView` | Full chip — background + border + shadow |
| `WorkingChipView` | Full chip — background + border + shadow |
| `ToolBlockView` | Full chip — canonical reference |
| `CollationSummaryChip` / group chips | Accent chip — coloured background/border, bordered |

- `ThinkingBlockView` and `WorkingChipView` are independent components; changing one must not touch the other — three regressions caused in a single session by conflating them
- Canvas overlap ≠ transcript CSS — z-index issues trace to `bringToFront`/`nextZIndex` in App.tsx; do not add `position: relative` + `zIndex` to transcript rows
- `textTransform: uppercase` corrupts number+unit strings (`${n}s` → `NS`); remove transform or render number and unit as separate elements
- Chip expand toggles: use `React.startTransition`; unexploded collation groups emit zero items (lazy cost is on expand mount, not data flow)
